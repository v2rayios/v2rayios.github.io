一、Quantumult X 到底是什么？

Quantumult X 是一款专为 iOS 平台设计的网络调试与代理工具。它结合了 VPN 与 HTTP 代理能力，既可以用于日常网络请求转发，也能用于更精细的流量管理。和传统意义上单一用途的代理软件不同，Quantumult X 的核心价值在于“可控”和“可定制”。

它具备几个非常鲜明的特点：

第一，轻量且高效。对于 iOS 设备来说，资源占用和续航表现非常重要。Quantumult X 在运行流畅度方面一直口碑不错，不会像某些重型工具那样明显拖慢系统。

第二，流量管理能力强。用户可以根据不同规则灵活切换代理模式，让国内流量直连、国外流量走代理，或者针对特定域名、IP、关键词进行精确分流。

第三，网络日志详细。对于需要调试网络请求的人来说，日志窗口非常关键。它能帮助你观察请求走向、判断规则是否命中、定位连接失败的原因。

第四，支持自定义脚本。Quantumult X 不只是“转发流量”，还可以通过脚本实现更自由的定制行为，比如修改请求、处理响应、自动签到、去广告、解锁部分功能等。

第五，协议支持丰富。它支持 Shadowsocks、Vmess、Trojan 等多种主流协议，能够适配不同服务商和自建节点的需求。

简单来说，Quantumult X 不是“一个节点软件”，而是一个网络请求管理平台。你给它什么规则，它就按什么逻辑工作；你配置得越细，它越能发挥价值。

二、Quantumult X 的主要功能有哪些？

在真正上手之前，先理解它的功能模块，会比盲目点按更容易建立全局认知。

1. HTTP 代理与 VPN 支持

Quantumult X 可以作为代理工具使用，也可以结合系统 VPN 模式接管流量。对于普通用户来说，最直观的体验就是：开启后，根据规则决定哪些流量走代理，哪些流量直连。

2. 流量过滤与重写

这是 Quantumult X 非常有吸引力的一部分。通过重写规则，用户可以修改 HTTP/HTTPS 请求和响应，实现去广告、替换内容、调整接口返回等效果。很多高级玩法都围绕重写展开。

3. 多种协议支持

它支持 Shadowsocks、Vmess、Trojan 等协议。不同协议适用于不同网络环境和服务端配置，用户可以根据自己的节点情况选择。

4. 丰富的配置与脚本支持

Quantumult X 支持远程配置、本地配置、脚本引用和定时任务。对于喜欢自动化的人来说，这意味着它可以不只是代理工具，还能成为日常网络工作流的一部分。

5. 精细的请求规则管理

你可以按照域名、IP、GeoIP、User-Agent、URL 正则等条件设置规则。规则越精细，分流越准确，体验越稳定。

Quantumult X 会不定期更新。新版本通常会修复问题、增强兼容性、优化脚本能力或调整规则逻辑。建议通过 App Store 保持自动更新，或者定期手动检查更新。对于依赖规则和脚本的用户来说，版本过旧有时会导致部分配置失效。

四、Quantumult X 的基础配置步骤

第一次使用时，不需要追求“一步到位”。先让基础代理跑通，再逐步加入规则、重写和脚本，才是更稳妥的路径。

1. 启动应用并熟悉主界面

打开 Quantumult X 后，你会看到多个功能区。主界面通常包含开关、节点、规则、日志、设置等入口。不要急着把所有选项都改一遍，先确认每个区域的作用。

2. 配置代理设置

点击设置图标，进入代理相关配置。根据你的服务商提供的信息，填写服务器地址、端口、密码、加密方式等参数。如果你使用的是订阅链接，也可以通过订阅方式导入，而不是手动逐个填写。

手动配置适合节点少、结构简单的情况；订阅配置适合节点多、经常更换的情况。对大多数用户来说，订阅更省事。

3. 配置路径规则

在“配置文件”中，可以设置流量的路由和过滤规则。规则决定了哪些请求直连、哪些走代理、哪些被拒绝。常见做法是：

  • 国内网站和 IP 直连；
  • 国外网站走代理；
  • 广告域名拒绝或重写；
  • 特定应用或服务单独指定节点。

如果你不想从零编写规则，可以使用远程配置，从云端直接获取配置。具体方式是打开“设置”中的“配置文件”，选择添加配置，然后输入配置 URL。这样更新规则时只需刷新配置即可。

4. 导入或编写重写规则

重写规则是 Quantumult X 的高级玩法之一。你可以点击规则配置中的重写脚本，直接导入线上规则库，也可以自己编写。很多用户会从 GitHub 等平台获取重写配置，通过 URL 在线导入。

导入时要注意规则来源是否可靠。重写规则本质上会修改请求和响应，如果来源不可信，可能带来隐私或安全风险。

五、怎样让 Quantumult X 更好用？

基础配置完成后，下一步就是优化体验。真正拉开差距的，往往不是“有没有节点”，而是“规则是否合理、配置是否清晰、维护是否及时”。

1. 定期更新策略

代理协议、规则格式和脚本接口都可能变化。定期更新 Quantumult X 本体、订阅配置和重写规则，可以避免很多莫名其妙的问题。

2. 使用网络健康监测

Quantumult X 内部的日志窗口非常有用。你可以通过它观察网络性能波动，判断某个节点是否延迟过高，或者某条规则是否错误拦截了请求。遇到问题时，先看日志，往往比反复开关代理更有效。

3. 定制界面显示

通过设置自定义主题、调整显示方式，可以让界面更符合自己的使用习惯。虽然这不影响核心功能，但能明显提升日常使用体验。

4. 分场景配置

如果你有多个使用场景，比如家里 Wi-Fi、公司网络、移动数据，可以针对不同网络环境设置不同策略。这样能避免“一套规则走天下”带来的不适配问题。

5. 控制规则数量

规则不是越多越好。过多、过杂的规则会增加维护成本，也可能导致匹配效率下降。建议保留真正需要的规则，定期清理失效条目。

六、常见问题解答

Quantumult X 需要越狱吗？

不需要。Quantumult X 可以在未越狱的 iOS 设备上运行。它的使用本身是合法的，但具体用途需要用户自行遵守当地法律法规和服务条款。

Quantumult X 怎样查看流量统计？

打开 Quantumult X 应用，进入主界面，选择“流量”选项，就可以查看每天的流量使用情况。这个功能适合监测用量、判断异常消耗。

Quantumult X 支持哪些协议？

它支持多种协议，包括但不限于 Shadowsocks、Vmess 和 Trojan。不同协议在不同网络环境下表现不同，可以按需选择。

如何解决 Quantumult X 连接不上网络的问题？

可以按以下顺序排查：

  1. 检查代理设置中的 IP、端口、密码、加密方式是否正确；
  2. 尝试更换其他节点，判断是否是单一节点故障；
  3. 检查规则是否误拦截了目标请求；
  4. 确认应用没有被防火墙、隐私控制或系统限制；
  5. 查看日志窗口，定位具体失败环节；
  6. 更新配置文件和重写规则，排除旧规则冲突。

如果问题依旧，建议先恢复到一个最简配置，只保留一个节点和基础规则，确认能否连通，再逐步加回复杂配置。

FAQ

Trojan 的伪装域名选择有哪些原则？
伪装域名必须是真实可访问网站，并且证书有效。这样可以让 Trojan 流量看起来像普通 HTTPS 请求，减少被封锁或 DPI 检测风险，确保节点安全和可用性。
Clash 节点测速如何提高访问效率？
Clash 会周期性检测节点延迟和丢包率，根据测试结果自动选择最优节点。结合策略组和分流规则，用户可体验更快的网页加载、视频播放和游戏连接速度，提高整体网络效率。
Netch 的 TUN 模式与 SOCKS 模式有何差异？
TUN 模式通过虚拟网卡拦截所有流量，更接近系统级代理；SOCKS 模式则仅作用于指定应用。TUN 模式更适合全局代理需求，而 SOCKS 模式轻量快捷，适用于游戏或单软件加速。
PassWall2 的“节点切换策略”如何配置？
在 PassWall2 中可设置多节点策略，如“按延迟排序”、“自动选择最快节点”等。程序会定期测速，根据实时数据自动切换线路，保证连接的稳定性和速度。
WinXray 支持 Hysteria 协议吗？
新版本的 WinXray 已整合了 V2Ray 内核更新，支持 Hysteria 协议。用户可通过导入 Clash 或 sing-box 类型的订阅使用基于 QUIC 的高性能连接，速度和稳定性均更出色。
Hiddify Next 如何实现用户流量分配？
管理员可为每个用户设置带宽和流量配额。超出限制时可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性和效率。
Clash 的自动测速功能如何设置？
Clash 支持定期测速节点延迟，用户可以设置测速频率和超时时间。测速结果会影响策略组的节点选择，从而自动切换至最优节点，提高访问速度和连接稳定性。
Hysteria2 协议的主要特点是什么？
Hysteria2 是新一代基于 QUIC 的高速代理协议，支持自适应拥塞控制和零 RTT 连接。相比传统 TCP 协议，它能在高延迟或丢包环境下保持稳定速度，特别适合跨境访问或实时传输场景。
V2Ray 的传输协议选择对性能有何影响？
V2Ray 支持 TCP、WebSocket、gRPC、QUIC 等多种传输协议。不同协议在延迟、抗封锁和吞吐量上差异明显。用户可根据网络环境选择最优协议，以获得稳定且高速的连接体验。
PassWall2 在路由器上使用 TUN 模式会有什么影响？
启用 TUN 模式会拦截并转发路由器上全部或选定流量，这会增加路由器 CPU 与内存负担，可能影响路由器其他服务表现。建议在性能足够的设备上启用，或仅对特定设备/端口进行分流。
